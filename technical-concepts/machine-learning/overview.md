This section provides technical details about the machine learning models and algorithms used in the Ona Intelligence Layer.

## What You Can Find Here

## Model Types

The platform uses two types of models:

*   **Generic Models**: Pre-trained on global datasets, available for all users
*   **Customer-Specific Models**: Fine-tuned on your site's historical data for higher accuracy
